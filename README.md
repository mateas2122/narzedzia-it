# Narzędzia IT

Prosta strona z przydatnymi narzędziami dla IT.

## Dostępne narzędzia

* Generator haseł
* Generator UUID

W planach:

* Hashowanie tekstu
* Kalkulator CHMOD

## Technologie

* HTML
* CSS
* JavaScript
* Beer CSS

Projekt działa bez backendu i nie wymaga instalowania dodatkowych zależności.

## Uruchomienie

Wystarczy otworzyć `index.html` w przeglądarce lub uruchomić projekt przez dowolny lokalny serwer HTTP.
